# Практическая работа «Транзакции, процедуры и триггеры в PostgreSQL»

**Дисциплина:** Базы данных  
**Продолжительность:** 80–90 минут  
**Уровень:** начальный  
**Цель:** закрепить работу с транзакциями (`BEGIN`, `COMMIT`, `ROLLBACK`, `SAVEPOINT`) и повторить ранее изученные процедуры и триггеры.

Практическая работа состоит из **8 заданий**, объединённых общей темой — управление банковскими счетами. Задания постепенно усложняются, но для их выполнения достаточно уже изученных конструкций SQL и PL/pgSQL.

## Подготовка базы данных

Перед началом работы выполните следующий код:

```sql
DROP TABLE IF EXISTS accounts CASCADE;

CREATE TABLE accounts (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    owner VARCHAR(100) NOT NULL,
    balance NUMERIC(12, 2) NOT NULL
        CHECK (balance >= 0)
);

INSERT INTO accounts (owner, balance)
VALUES
    ('Али', 10000),
    ('Мурад', 5000),
    ('Анна', 15000),
    ('Давид', 8000),
    ('Мария', 12000);
```

Проверьте содержимое таблицы:

```sql
SELECT * FROM accounts;
```

| id | owner | balance |
|---|---|---:|
| 1 | Али | 10000 |
| 2 | Мурад | 5000 |
| 3 | Анна | 15000 |
| 4 | Давид | 8000 |
| 5 | Мария | 12000 |

Все задания выполняются последовательно. После каждого задания проверяйте результат с помощью `SELECT`.

## Задание 1. Банковский перевод

**Уровень:** простой · **Время:** 5 минут.

Али решил перевести Мураду 2 000 рублей.

Напишите транзакцию, которая:

- Списывает 2 000 рублей со счёта Али.
- Начисляет 2 000 рублей на счёт Мурада.
- Подтверждает изменения командой `COMMIT`.

**Используйте:** `BEGIN`, `UPDATE`, `COMMIT`.

Проверьте, что после перевода у Али осталось 8 000 рублей, а у Мурада стало 7 000 рублей.

## Задание 2. Отмена покупки

**Уровень:** простой · **Время:** 5 минут.

Анна собиралась купить телефон за 6 000 рублей, но передумала.

Напишите транзакцию, которая:

- Списывает 6 000 рублей со счёта Анны.
- Показывает текущий баланс с помощью `SELECT`.
- Отменяет покупку командой `ROLLBACK`.
- Повторно показывает баланс.

**Вопрос:** почему после отмены баланс Анны снова составляет 15 000 рублей?

## Задание 3. Ошибка при переводе

**Уровень:** простой · **Время:** 10 минут.

Давид случайно попытался списать со своего счёта 20 000 рублей, хотя у него только 8 000.

Выполните следующие команды по очереди:

```sql
BEGIN;

UPDATE accounts
SET balance = balance - 20000
WHERE id = 4;
```

PostgreSQL должен сообщить об ошибке, поскольку баланс не может быть отрицательным.

После ошибки выполните:

```sql
ROLLBACK;
```

Проверьте баланс Давида.

**Ответьте на вопросы:**

- Почему PostgreSQL запретил операцию?
- Какую роль сыграло ограничение `CHECK`?
- Зачем после ошибки выполнять `ROLLBACK`?

## Задание 4. Три покупки и одна отмена

**Уровень:** средний · **Время:** 10 минут.

Мария совершает три покупки:

| Покупка | Стоимость |
|---|---:|
| Книга | 500 ₽ |
| Наушники | 2 000 ₽ |
| Клавиатура | 1 500 ₽ |

После покупки наушников она передумала покупать клавиатуру.

Напишите одну транзакцию, которая:

1. Списывает 500 рублей.
2. Списывает 2 000 рублей.
3. Создаёт точку сохранения `before_keyboard`.
4. Списывает 1 500 рублей.
5. Отменяет только покупку клавиатуры через `ROLLBACK TO SAVEPOINT`.
6. Подтверждает оставшиеся покупки через `COMMIT`.

**Ожидаемый баланс Марии:** 9 500 рублей.

## Задание 5. Процедура пополнения счёта

**Уровень:** средний · **Время:** 10 минут.

Банк хочет упростить пополнение счетов.

Создайте процедуру `deposit_money`, которая принимает два параметра:

- `account_id INTEGER` — номер счёта.
- `amount NUMERIC` — сумма пополнения.

Процедура должна увеличивать баланс выбранного счёта на указанную сумму.

**Подсказка — структура процедуры:**

```sql
CREATE OR REPLACE PROCEDURE deposit_money(
    account_id INTEGER,
    amount NUMERIC
)
LANGUAGE plpgsql
AS $$
BEGIN
    -- Напишите UPDATE для пополнения счёта
END;
$$;
```

Вызовите процедуру внутри транзакции:

```sql
BEGIN;

CALL deposit_money(1, 3000);

COMMIT;
```

Проверьте баланс Али.

**Дополнительное задание:** добавьте проверку `IF`, которая запрещает пополнение на отрицательную сумму.

## Задание 6. Триггер: уведомление о крупном пополнении

**Уровень:** средний · **Время:** 10 минут.

Банк хочет получать уведомление, если баланс счёта увеличивается более чем на 5 000 рублей за одну операцию.

Создайте триггерную функцию `notify_large_deposit()`.

Она должна:

- Срабатывать после `UPDATE` таблицы `accounts`.
- Сравнивать `NEW.balance` и `OLD.balance`.
- Выводить `RAISE NOTICE 'Крупное пополнение счёта!'`, если разница больше 5 000.

**Подсказка:**

```sql
IF NEW.balance - OLD.balance > 5000 THEN
    RAISE NOTICE 'Крупное пополнение счёта!';
END IF;
```

Создайте триггер `large_deposit_trigger` и проверьте его:

```sql
CALL deposit_money(2, 6000);
```

Попробуйте также пополнить счёт на 1 000 рублей.

**Вопрос:** почему в одном случае уведомление появляется, а в другом нет?

## Задание 7. История банковских операций

**Уровень:** средний · **Время:** 15 минут.

Банк хочет автоматически сохранять историю изменения баланса.

Создайте таблицу:

```sql
CREATE TABLE balance_history (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    account_id INTEGER,
    old_balance NUMERIC,
    new_balance NUMERIC,
    changed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

Создайте триггерную функцию `save_balance_history()`, которая при изменении баланса добавляет запись в эту таблицу.

**Подсказка:**

```sql
INSERT INTO balance_history (
    account_id,
    old_balance,
    new_balance
)
VALUES (
    OLD.id,
    OLD.balance,
    NEW.balance
);
```

Создайте триггер:

```sql
CREATE TRIGGER balance_history_trigger
AFTER UPDATE ON accounts
FOR EACH ROW
EXECUTE FUNCTION save_balance_history();
```

Проверьте работу:

```sql
CALL deposit_money(3, 2000);

SELECT * FROM balance_history;
```

**Дополнительное задание:** выполните изменение баланса внутри транзакции, затем сделайте `ROLLBACK`. Проверьте, появилась ли запись об отменённом изменении в истории.

## Задание 8. Банковский бонус

**Уровень:** творческое · **Время:** 10 минут.

Банк проводит акцию: каждому клиенту начисляется бонус 500 рублей.

Создайте процедуру `give_bonus()`, которая увеличивает баланс **всех клиентов** на 500 рублей.

Вызовите её внутри транзакции:

```sql
BEGIN;

CALL give_bonus();

SELECT * FROM accounts;

ROLLBACK;
```

Проверьте, что после `ROLLBACK` все бонусы отменились.

Затем повторите операцию, но вместо `ROLLBACK` используйте `COMMIT`.

**Вопрос:** как изменится таблица `balance_history`, если триггер из задания 7 уже создан?
