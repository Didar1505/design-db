# Практическое задание: работа с `TRIGGER`

Используя существующую базу данных транспортной системы, создайте триггеры для автоматического выполнения действий при добавлении, изменении и удалении данных.

## Задание 1. Автоматическое изменение баланса

Создайте триггер `update_card_balance`, который будет срабатывать **после добавления новой записи** в таблицу `transactions`.

Триггер должен:

- определить карту через `NEW.card_id`;
- получить сумму операции через `NEW.amount`;
- автоматически прибавить `amount` к текущему `balance` карты.

Проверьте работу триггера:

```sql
INSERT INTO transactions (card_id, station_id, amount, type)
VALUES (1, 1, -2.50, 'enter');
```

Проверьте баланс карты до и после выполнения операции:

```sql
SELECT * FROM cards
WHERE id = 1;
```

---

## Задание 2. Возврат баланса при удалении операции

Создайте триггер `restore_card_balance`, который будет срабатывать **после удаления записи** из таблицы `transactions`.

Если операция удаляется, её влияние на баланс карты должно быть отменено.

Для получения информации об удалённой операции используйте:

```sql
OLD.amount
OLD.card_id
```

Например, если удаляется операция:

```text
amount = -2.50
```

на баланс соответствующей карты должно вернуться `2.50`.

Проверьте работу триггера:

1. Посмотрите текущий баланс карты.
2. Удалите одну из её операций.
3. Снова проверьте баланс карты.

## Задание 3. Создание журнала изменения баланса

Создайте новую таблицу `balance_log`:

```sql
CREATE TABLE balance_log (
    id INTEGER PRIMARY KEY,
    card_id INTEGER,
    old_balance NUMERIC,
    new_balance NUMERIC,
    changed_at NUMERIC DEFAULT CURRENT_TIMESTAMP
);
```

Создайте триггер, который будет срабатывать **после изменения `balance`** в таблице `cards`.

При каждом изменении баланса триггер должен автоматически записывать в `balance_log`:

- `card_id`;
- старый баланс — `OLD.balance`;
- новый баланс — `NEW.balance`;
- дату и время изменения.

Проверьте работу триггера:

```sql
UPDATE cards
SET balance = balance + 10
WHERE id = 1;
```

После этого проверьте журнал:

```sql
SELECT * FROM balance_log;
```

## Задание 4. Исследование `NEW` и `OLD`

Определите, какие значения можно использовать внутри триггера для каждого события:

- `INSERT` — `NEW` или `OLD`;
- `DELETE` — `NEW` или `OLD`;
- `UPDATE` — `NEW`, `OLD` или оба.
