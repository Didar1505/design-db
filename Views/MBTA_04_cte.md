# Практическое задание: Common Table Expression (`CTE`)

`CTE` позволяет создать временный результат, похожий на `VIEW`, но существующий **только внутри одного SQL-запроса**.

Для создания используется конструкция:

```sql
WITH name AS (
    SELECT ...
)
SELECT *
FROM name;
```

## Задание 1. Активные карты

С помощью `CTE` создайте временный результат:

```text
active_cards
```

В него должны попадать только карты:

```text
deleted = 0
```

После этого из `active_cards` выберите только карты, баланс которых больше `20`.

Используйте структуру:

```sql
WITH active_cards AS (
    -- запрос
)
SELECT *
FROM active_cards
-- условие;
```

После выполнения попробуйте отдельно выполнить:

```sql
SELECT * FROM active_cards;
```

Объясните, почему этот запрос уже не работает.

## Задание 2. Статистика операций

С помощью `CTE` создайте временный результат:

```text
card_statistics
```

Для каждой карты рассчитайте:

- `card_id`;
- количество операций — `transaction_count`;
- общую сумму операций — `total_amount`.

Используйте:

```text
GROUP BY
COUNT()
SUM()
```

После этого в основном запросе выведите только карты, у которых:

```text
transaction_count >= 2
```

Используйте структуру:

```sql
WITH card_statistics AS (
    -- агрегирование данных
)
SELECT *
FROM card_statistics
-- условие;
```

Сравните время существования результатов:

```text
VIEW      → сохраняется в базе данных
TEMP VIEW → существует до закрытия соединения
CTE       → существует только во время одного запроса
```
