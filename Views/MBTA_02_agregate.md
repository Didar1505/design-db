# Практическое задание: агрегация и группировка данных

Используя базу данных транспортной системы, выполните запросы для анализа данных с помощью агрегатных функций:

- `COUNT()` — количество записей;
- `SUM()` — сумма значений;
- `AVG()` — среднее значение;
- `MIN()` — минимальное значение;
- `MAX()` — максимальное значение;
- `GROUP BY` — группировка данных;
- `HAVING` — фильтрация групп.

## Задание 1. Количество транспортных карт

Определите общее количество карт в таблице `cards`.

Затем отдельно определите:

- количество активных карт (`deleted = 0`);
- количество удалённых карт (`deleted = 1`).

---

## Задание 2. Анализ баланса

Для активных транспортных карт определите:

- средний баланс;
- минимальный баланс;
- максимальный баланс;
- сумму средств на всех активных картах.

Используйте `AVG()`, `MIN()`, `MAX()` и `SUM()`.

---

## Задание 3. Количество операций

Определите общее количество записей в таблице `transactions`.

Результат выведите под названием:

```text
transaction_count
```

---

## Задание 4. Группировка операций по типу

Определите количество операций каждого типа:

```text
enter
exit
deposit
```

Используйте `GROUP BY`.

Результат должен содержать:

```text
type | transaction_count
```

---

## Задание 5. Операции каждой карты

Определите, сколько операций совершено каждой транспортной картой.

Сгруппируйте данные по:

```text
card_id
```

Выведите:

- `card_id`;
- количество операций.

---

## Задание 6. Операции на станциях

Определите количество операций, совершённых на каждой станции.

Сначала выполните группировку по:

```text
station_id
```

Затем усложните запрос: используйте `JOIN` с таблицей `stations`, чтобы вместо `station_id` вывести название станции.

Результат должен содержать:

```text
station_name | transaction_count
```

---

## Задание 7. Анализ линий

Определите количество станций на каждой линии метро.

Сгруппируйте таблицу `stations` по:

```text
line
```

Выведите:

```text
line | station_count
```

---

## Задание 8. Анализ тарифных зон

Определите количество станций в каждой тарифной зоне.

Используйте:

```sql
GROUP BY zone
```

---

## Задание 9. Общая сумма пополнений

Определите общую сумму всех операций:

```text
type = 'deposit'
```

Используйте `SUM()`.

Операции `enter` и `exit` не должны учитываться.

---

## Задание 10. Пополнения каждой карты

Определите общую сумму пополнений отдельно для каждой транспортной карты.

Результат должен содержать:

```text
card_id | total_deposited
```

Используйте одновременно:

- `WHERE`;
- `SUM()`;
- `GROUP BY`.

---

## Задание 11. Использование `HAVING`

Найдите карты, которые имеют **больше двух операций**.

Используйте:

```sql
GROUP BY card_id
```

и отфильтруйте полученные группы с помощью `HAVING`.

Результат должен содержать:

```text
card_id | transaction_count
```

---

## Задание 12. Активные карты с большим количеством операций

Найдите только **активные карты**, которые совершили две или более операций.

Для выполнения задания необходимо использовать:

- `JOIN`;
- `WHERE`;
- `GROUP BY`;
- `COUNT()`;
- `HAVING`.

Не учитывайте карты:

```text
deleted = 1
```

---

## Задание 13. Аналитический запрос

Определите количество операций на каждой линии метро.

Для этого необходимо связать:

```text
transactions
      ↓
stations
```

Сгруппируйте результат по `line`.

Выведите:

```text
line | transaction_count
```

---

## Задание 14. Самостоятельный анализ

Самостоятельно составьте запрос, который отвечает на вопрос:

**Какие станции имеют больше двух зарегистрированных операций?**

В результате выведите:

- название станции;
- линию;
- количество операций.

Используйте:

```text
JOIN
GROUP BY
COUNT()
HAVING
```
