# Практическая работа №15
## PostgreSQL — работа с массивами, таблицами и CSV-файлами

**Цель работы:** закрепить навыки использования массивов в PL/pgSQL, обработки данных с помощью `FOREACH`, `ARRAY_AGG`, `UNNEST`, а также импорта и экспорта CSV-файлов.

**Инструменты:** PostgreSQL, pgAdmin или psql, VS Code.

### Общие требования

1. Создайте базу данных `practice15_db`.
2. Все задания выполняйте самостоятельно.
3. Сохраняйте SQL-код в файлы `task1.sql`, `task2.sql` и так далее.
4. Используйте переменные, массивы, циклы и SQL-запросы согласно условиям.
5. Проверяйте результаты выполнения каждого задания.

## Задание 1. Анализ продаж магазина

Магазин записал количество проданных товаров за последние семь дней.

Создайте массив:

```sql
sales INTEGER[] := ARRAY[12, 8, 15, 6, 20, 11, 18];
```

Используя `FOREACH`, выполните следующие действия:

1. Выведите продажи за каждый день.
2. Рассчитайте общее количество проданных товаров.
3. Определите, сколько дней продажи превышали 10 товаров.
4. Найдите максимальное количество продаж за день.
5. Рассчитайте среднее количество продаж за день.

**Условие:** вычисления необходимо выполнить с помощью переменных и цикла `FOREACH`, без использования агрегатных функций SQL.

## Задание 2. Обработка списка сотрудников

Компания хранит имена сотрудников в массиве.

```sql
employees TEXT[] := ARRAY[
    'Александр', 'Мария', 'Иван', 'Анна', 'Дмитрий'
];
```

Напишите блок PL/pgSQL, который:

1. Выводит всех сотрудников по одному.
2. Определяет общее количество сотрудников.
3. Добавляет в массив двух новых сотрудников.
4. Удаляет сотрудника «Иван».
5. Выводит обновлённый массив.
6. Проверяет, существует ли сотрудник «Анна» в массиве.

Используйте `ARRAY_APPEND`, `ARRAY_REMOVE`, `CARDINALITY` и `FOREACH`.

## Задание 3. Результаты экзамена

Создайте таблицу `exam_results`:

| Столбец | Тип данных |
|---|---|
| id | Автоматический идентификатор |
| student_name | VARCHAR(100) |
| score | INTEGER |

Добавьте минимум 10 студентов с разными результатами экзамена от 0 до 100.

Напишите программный блок, который:

1. Получает все результаты экзамена в массив через `ARRAY_AGG`.
2. Выводит полученный массив.
3. Подсчитывает количество студентов, набравших 60 и более баллов.
4. Определяет количество студентов, не сдавших экзамен.
5. Вычисляет средний балл с помощью `FOREACH`.

**Дополнительное условие:** получите отдельный массив результатов студентов, набравших 90 и более баллов.

## Задание 4. Автоматическое заполнение склада

Создайте таблицу `warehouse`:

| Столбец | Тип данных |
|---|---|
| id | Автоматический идентификатор |
| product_name | TEXT |
| quantity | INTEGER |

Даны два массива:

```sql
products TEXT[] := ARRAY[
    'Ноутбук', 'Монитор', 'Клавиатура',
    'Мышь', 'Принтер'
];

quantities INTEGER[] := ARRAY[5, 8, 20, 30, 4];
```

Необходимо:

1. Используя цикл `FOR`, перенести данные из двух массивов в таблицу `warehouse`.
2. Каждому товару должно соответствовать количество с тем же индексом.
3. Вывести все товары из таблицы.
4. Найти товары, количество которых меньше 10.
5. Подсчитать общее количество единиц товаров на складе.

**Дополнительно:** выполните заполнение таблицы без цикла, используя `UNNEST` для обоих массивов.

## Задание 5. Обработка заказов

Интернет-магазин получил список сумм заказов.

```sql
orders NUMERIC[] := ARRAY[
    1200, 4500, 800, 7200, 1500, 9900, 300
];
```

Напишите программу, которая:

1. Перебирает все суммы заказов.
2. Вычисляет общую выручку.
3. Определяет количество заказов дороже 3000 рублей.
4. Рассчитывает сумму скидки 10% для каждого заказа дороже 5000 рублей.
5. Создаёт новый массив с итоговыми суммами заказов после применения скидок.
6. Выводит исходный и обновлённый массивы.

Для формирования нового массива используйте `ARRAY_APPEND`.

## Задание 6. Импорт списка книг из CSV

Создайте CSV-файл `books.csv` со следующими столбцами:

```csv
title,author,year,price
```

Самостоятельно заполните файл минимум 10 книгами с разными авторами, годами публикации и ценами.

Создайте таблицу `books` с подходящими типами данных.

Необходимо:

1. Импортировать данные из CSV-файла в PostgreSQL.
2. Проверить количество импортированных записей.
3. Вывести книги, опубликованные после 2020 года.
4. Найти три самые дорогие книги.
5. Рассчитать среднюю стоимость книг.
6. Получить массив названий всех книг через `ARRAY_AGG`.

Для импорта используйте `\copy` через `psql` или инструмент Import/Export в pgAdmin.

## Задание 8. Учёт расходов

Создайте таблицу `expenses`:

| id | Автоматический идентификатор |

Создайте CSV-файл `expenses.csv`, содержащий минимум 12 расходов из разных категорий, например: транспорт, питание, интернет, обучение, развлечения.

Необходимо:

5. Найти категорию с наибольшей общей суммой расходов.
6. Экспортировать расходы больше 1000 рублей в файл `large_expenses.csv`.

## Задание 9. Генерация уникальных кодов

Создайте таблицу `devices`:

| Столбец | Тип данных |
|---|---|
| id | Автоматический идентификатор |
| device_code | VARCHAR(20), UNIQUE |
| status | VARCHAR(20) |

Создайте массив из 10 кодов устройств:

```sql
codes TEXT[] := ARRAY[
    'DEV-001', 'DEV-002', 'DEV-003',
    'DEV-004', 'DEV-005', 'DEV-006',
    'DEV-007', 'DEV-008', 'DEV-009', 'DEV-010'
];
```

Напишите блок PL/pgSQL, который:

1. Перебирает массив кодов.
2. Добавляет каждый код в таблицу `devices`.
3. Присваивает всем устройствам статус `available`.
4. Выводит количество добавленных устройств.
5. Получает из таблицы массив всех кодов устройств.
6. Проверяет, присутствует ли код `DEV-005` в полученном массиве.

**Дополнительно:** измените программу так, чтобы повторное выполнение не создавало ошибки из-за дублирования кодов.

## Задание 10. Итоговый мини-проект «Учёт успеваемости»

Создайте таблицу `student_grades`:

| Столбец | Тип данных |
|---|---|
| id | Автоматический идентификатор |
| student_name | VARCHAR(100) |
| subject | VARCHAR(100) |
| grade | INTEGER |

Подготовьте CSV-файл `student_grades.csv` минимум с 15 записями. У каждого студента может быть несколько оценок по разным предметам.

Необходимо:

1. Импортировать CSV-файл в PostgreSQL.
2. Вывести всех студентов и их оценки.
3. Получить массив всех оценок через `ARRAY_AGG`.
4. Используя `FOREACH`, вычислить среднюю оценку по всем записям.
5. Определить количество оценок 5.
6. Вывести студентов, имеющих хотя бы одну неудовлетворительную оценку (2).
7. Создать таблицу `excellent_students` для хранения имён студентов, у которых все оценки равны 5.
8. Заполнить таблицу `excellent_students` с помощью SQL-запроса.
9. Экспортировать список отличников в CSV-файл `excellent_students.csv`.

**Дополнительное задание:** получить массив имён отличников из таблицы `excellent_students` и вывести его через `RAISE NOTICE`.
