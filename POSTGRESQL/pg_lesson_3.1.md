# Практическая работа №16
## Создание и использование функций в PostgreSQL (PL/pgSQL)

**Тема:** Пользовательские функции, параметры, возвращаемые значения и работа с SQL-таблицами.  
**Продолжительность:** 90 минут  
**Уровень:** от базового до среднего.

**Цель:** научиться самостоятельно создавать функции PostgreSQL, использовать параметры, условия, переменные, SQL-запросы и возвращать результаты разных типов.

В работе предусмотрено 10 заданий. Первые три посвящены основам функций, следующие четыре — работе с таблицами, последние три — более сложным задачам.

## Задание 1. Калькулятор стоимости покупки

Создайте функцию `calculate_total(price NUMERIC, quantity INTEGER)`.

**Требования:**

1. Функция принимает цену одного товара и количество.
2. Вычисляет общую стоимость покупки.
3. Если цена или количество отрицательные, возвращает `NULL`.
4. Возвращает результат типа `NUMERIC`.

Примеры проверки:

```sql
SELECT calculate_total(1500, 3);
SELECT calculate_total(250, 10);
SELECT calculate_total(-100, 5);
```

Ожидаемые результаты: `4500`, `2500`, `NULL`.

## Задание 2. Определение категории покупателя

Создайте функцию `customer_level(total_spent NUMERIC)`.

Функция должна определять категорию покупателя по общей сумме покупок.

| Сумма покупок | Категория |
|---|---|
| Менее 10 000 | Bronze |
| От 10 000 до 49 999,99 | Silver |
| От 50 000 до 99 999,99 | Gold |
| От 100 000 | Platinum |

**Требования:**

1. Используйте `IF`, `ELSIF`, `ELSE`.
2. Возвращайте значение `TEXT`.
3. Для отрицательной суммы возвращайте `Некорректная сумма`.

## Задание 3. Расчёт заработной платы с премией

Создайте функцию `calculate_bonus(salary NUMERIC, years INTEGER)`.

Функция должна рассчитывать итоговую зарплату с премией в зависимости от стажа.

| Стаж | Премия |
|---|---|
| Менее 1 года | 0% |
| От 1 до 3 лет включительно | 5% |
| От 4 до 7 лет | 10% |
| Более 7 лет | 20% |

**Требования:**

1. Принимайте зарплату и стаж.
2. Используйте локальную переменную для расчёта премии.
3. Возвращайте итоговую зарплату.
4. Для отрицательной зарплаты или стажа возвращайте `NULL`.

## Задание 4. Получение информации о товаре

Используйте таблицу `products`.

Создайте функцию `get_product_info(product_id INTEGER)`.

Функция должна возвращать текст с информацией о товаре.

Пример результата:

```text
Товар: Ноутбук Lenovo, Цена: 65000, Остаток: 8
```

**Требования:**

1. Получите данные товара с помощью `SELECT ... INTO`.
2. Сохраните название, цену и количество в локальные переменные.
3. Сформируйте строку с результатом.
4. Если товар отсутствует, верните `Товар не найден`.

## Задание 6. Средняя оценка студента

Используйте таблицы `students` и `grades`.

Создайте функцию `student_average(student_id INTEGER)`.

**Требования:**

1. Получите все оценки выбранного студента.
2. Рассчитайте среднюю оценку с помощью `AVG`.
3. Округлите результат до двух знаков после запятой.
4. Верните результат типа `NUMERIC`.
5. Если студент отсутствует или не имеет оценок, верните `NULL`.

Проверьте функцию для всех студентов:

```sql
SELECT
    full_name,
    student_average(id) AS average_grade
FROM students;
```

Создайте функцию `low_stock_products(limit_quantity INTEGER)`.

**Требования:**

1. Найдите товары, остаток которых меньше указанного значения.

## Задание 9. Изменение цены товара через функцию

Создайте функцию `increase_product_price(product_id INTEGER, percent NUMERIC)`.

**Требования:**

1. Принимайте идентификатор товара и процент увеличения цены.
2. Проверьте, что процент неотрицательный.
3. Найдите товар по идентификатору.
4. Увеличьте цену с помощью `UPDATE`.
5. Верните новую цену.
6. Если товар не найден или процент отрицательный, верните `NULL`.

```sql
SELECT * FROM products;
```

**Дополнительное условие:** не допускайте изменения цены других товаров.

## Задание 10. Отчёт об успеваемости студентов

Создайте функцию `get_student_report(min_average NUMERIC)`.

Функция должна возвращать таблицу:

| Студент | Группа | Средняя оценка | Статус |
|---|---|---|---|

Статус определяется следующим образом:

- Средняя оценка от 4,5 — `Отличник`.
- Средняя оценка от 3,5 до значения меньше 4,5 — `Хорошист`.
- Средняя оценка от 3 до значения меньше 3,5 — `Удовлетворительно`.
- Средняя оценка ниже 3 — `Неуспевающий`.

**Требования:**

1. Используйте `RETURNS TABLE` и `RETURN QUERY`.
2. Получите данные из таблиц `students` и `grades`.
3. Рассчитайте среднюю оценку каждого студента.
4. Выведите только студентов, средняя оценка которых не ниже `min_average`.
5. Определите статус с помощью `CASE`.
6. Отсортируйте студентов по средней оценке по убыванию.

Пример:

```sql
SELECT * FROM get_student_report(4.0);
```
