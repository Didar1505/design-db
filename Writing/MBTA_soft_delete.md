# Практическое задание: Soft Delete

Вместо физического удаления транспортных карт реализуйте принцип **Soft Delete**.

Запись должна оставаться в таблице `cards`, но специальный столбец будет определять, является карта активной или удалённой.

## Задание 1. Добавление столбца `deleted`

Добавьте в таблицу `cards` новый столбец:

- название — `deleted`;
- тип — `INTEGER`;
- значение по умолчанию — `0`.

Используйте команду `ALTER TABLE`.

Значения столбца:

```text
0 — карта активна
1 — карта удалена
```

После изменения проверьте структуру таблицы:

```sql
.schema cards
```

---

## Задание 2. Мягкое удаление карты

Не используя `DELETE`, пометьте карту с:

```text
id = 3
```

как удалённую.

Для этого измените значение `deleted` с `0` на `1` с помощью команды `UPDATE`.

После выполнения операции проверьте результат:

```sql
SELECT * FROM cards
WHERE id = 3;
```

---

## Задание 3. Получение только активных карт

Напишите запрос, который выводит только карты, которые **не были удалены**.

В результате должны отображаться записи:

```text
deleted = 0
```

---

## Задание 4. Получение удалённых карт

Напишите запрос, который показывает только карты, помеченные как удалённые:

```text
deleted = 1
```

---

## Задание 5. Восстановление карты

Карта с `id = 3` была удалена по ошибке.

Восстановите её, не создавая новую запись.

После восстановления карта снова должна иметь:

```text
deleted = 0
```

Проверьте результат с помощью `SELECT`.

---

## Задание 6. Массовое мягкое удаление

Пометьте как удалённые все карты, баланс которых меньше:

```text
10
```

Перед выполнением `UPDATE` сначала найдите эти карты с помощью `SELECT`.

После изменения выведите отдельно:

- все активные карты;
- все удалённые карты.

---

## Контрольный вопрос

Объясните разницу между следующими операциями:

```sql
DELETE FROM cards
WHERE id = 3;
```

и:

```sql
UPDATE cards
SET deleted = 1
WHERE id = 3;
```

В каком случае запись можно легко восстановить?
