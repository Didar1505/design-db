# Практическое задание: работа с `VIEW`

Используя существующую базу данных транспортной системы, создайте несколько представлений (`VIEW`) для удобной работы с данными.

## Задание 1. Представление активных карт

Создайте представление:

```text
active_cards
```

Оно должно содержать только карты, у которых:

```text
deleted = 0
```

В представлении должны отображаться:

- `id`;
- `balance`;
- `created_at`.

После создания проверьте результат:

```sql
SELECT * FROM active_cards;
```

---

## Задание 2. Представление удалённых карт

Создайте представление:

```text
deleted_cards
```

которое показывает только карты, помеченные как удалённые:

```text
deleted = 1
```

Проверьте работу представления с помощью `SELECT`.

---

## Задание 3. Представление станций первой зоны

Создайте представление:

```text
zone_one_stations
```

Оно должно содержать только станции:

```text
zone = 1
```

Выведите из представления:

- `id`;
- `name`;
- `line`.

После создания выполните:

```sql
SELECT * FROM zone_one_stations;
```

---

## Задание 4. Представление истории операций

Создайте представление:

```text
transaction_details
```

которое объединяет данные из таблиц `transactions` и `stations`.

Для каждой операции необходимо вывести:

- `transactions.id`;
- `card_id`;
- название станции;
- линию станции;
- `amount`;
- `type`;
- `datetime`.

Для объединения таблиц используйте `JOIN`.

После создания выполните:

```sql
SELECT * FROM transaction_details;
```

---

## Задание 5. Представление операций активных карт

Создайте представление:

```text
active_card_transactions
```

Оно должно показывать операции только тех карт, у которых:

```text
deleted = 0
```

Для этого объедините таблицы:

```text
cards
    ↓
transactions
    ↓
stations
```

В результате необходимо вывести:

- `card_id`;
- `balance`;
- название станции;
- `amount`;
- `type`;
- `datetime`.

---

## Задание 6. Проверка работы `VIEW`

Выберите одну активную карту и пометьте её как удалённую:

```sql
UPDATE cards
SET deleted = 1
WHERE id = ...;
```

После этого снова выполните:

```sql
SELECT * FROM active_cards;
```

Ответьте на вопросы:

1. Осталась ли карта в таблице `cards`?
2. Отображается ли она в `active_cards`?
3. Хранит ли `VIEW` отдельную копию данных?

---

## Задание 7. Удаление представления

Удалите представление:

```text
deleted_cards
```

с помощью команды:

```sql
DROP VIEW ...
```

После этого убедитесь, что исходная таблица `cards` и её данные не были удалены.

## Контрольные вопросы

1. Что такое `VIEW`?
2. Чем `VIEW` отличается от обычной таблицы?
3. Хранятся ли данные непосредственно внутри обычного `VIEW`?
4. Для чего удобно использовать `VIEW` при реализации Soft Delete?
5. Что произойдёт с `VIEW`, если данные исходной таблицы изменятся?
6. Может ли одно представление использовать данные нескольких таблиц?
