# Часть I. Подготовка базы данных

**Этот код предоставляется в готовом виде.** Выполните его в отдельной учебной базе данных PostgreSQL. Изменять код не требуется.

## 1. Таблица товаров

```sql
CREATE TABLE products (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    price NUMERIC(10, 2) NOT NULL CHECK (price > 0),
    quantity INTEGER NOT NULL CHECK (quantity >= 0)
);

INSERT INTO products (name, price, quantity)
VALUES
    ('Шахматы', 1200, 8),
    ('Монополия', 2500, 5),
    ('Уно', 500, 15),
    ('Дженга', 900, 10),
    ('Мафия', 700, 12),
    ('Пазл 1000 деталей', 1500, 4);
```

## 2. Таблица продаж

```sql
CREATE TABLE sales (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    product_id INTEGER REFERENCES products(id),
    quantity INTEGER NOT NULL CHECK (quantity > 0),
    total NUMERIC(10, 2) NOT NULL CHECK (total > 0),
    sold_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

INSERT INTO sales (product_id, quantity, total)
VALUES
    (3, 2, 1000),
    (1, 1, 1200);
```

## 3. Таблица истории остатков

```sql
CREATE TABLE stock_history (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    product_id INTEGER REFERENCES products(id),
    old_quantity INTEGER,
    new_quantity INTEGER,
    changed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

Таблица `stock_history` пока пустая. Она начнёт заполняться автоматически после выполнения задания 3.

## 4. Проверка исходных данных

```sql
SELECT * FROM products ORDER BY id;
SELECT * FROM sales ORDER BY id;
SELECT * FROM stock_history ORDER BY id;
```

|---:|---|---:|---:|
| 1 | Шахматы | 1 200 | 8 |
| 2 | Монополия | 2 500 | 5 |
| 3 | Уно | 500 | 15 |
| 4 | Дженга | 900 | 10 |
| 5 | Мафия | 700 | 12 |
| 6 | Пазл 1000 деталей | 1 500 | 4 |

## Задание 1. Функция расчёта стоимости покупки

**Ориентировочное время:** 15 минут

Покупатель выбирает настольную игру и указывает, сколько экземпляров хочет приобрести.

**Задача:** создайте функцию `calculate_cost()`, которая рассчитывает общую стоимость покупки.

- `product_id INTEGER` — идентификатор товара.

## Задание 2. Процедура пополнения склада

**Тема:** процедуры  
**Баллы:** 15  
**Ориентировочное время:** 15 минут

На склад магазина поступают новые партии товаров. Для упрощения работы сотрудников необходимо создать процедуру пополнения.

**Задача:** создайте процедуру `add_stock()`.

**Параметры:**

- `product_id INTEGER` — идентификатор товара.
- `amount INTEGER` — количество поступивших экземпляров.

**Требования:**

1. Использовать условие `IF`.
2. Если `amount > 0`, увеличить количество выбранного товара через `UPDATE`.
3. После пополнения вывести `RAISE NOTICE 'Склад пополнен'`.
4. Если `amount <= 0`, вызвать `RAISE EXCEPTION` с сообщением об ошибке.

**Проверка:**

```sql
CALL add_stock(6, 5);
CALL add_stock(3, 10);

SELECT * FROM products ORDER BY id;
```

**Ожидаемые изменения:**

| Товар | Было | Добавлено | Стало |
|---|---:|---:|---:|
| Пазл 1000 деталей | 4 | 5 | 9 |
| Уно | 15 | 10 | 25 |

**Дополнительная проверка:**

```sql
CALL add_stock(1, -5);
```

Процедура должна вызвать ошибку, а количество шахмат не должно измениться.

## Задание 3. Триггер истории изменения остатков

**Ориентировочное время:** 20 минут

4. Использовать переменные `OLD` и `NEW`.
5. Создать триггер `stock_history_trigger`, который срабатывает `AFTER UPDATE` для каждой изменённой строки таблицы `products`.

| 4 | 10 | 15 |


## Задание 10. Несколько покупок с частичной отменой

Покупатель выбрал две игры:

- 2 экземпляра «Дженги».
- 3 экземпляра «Уно».

Покупатель сначала оформил обе покупки, но затем решил отказаться от «Уно». Нужно сохранить первую покупку и отменить только вторую.

**Задача:** напишите **одну транзакцию**, которая:

1. Начинается командой `BEGIN`.

4. Создаёт точку `SAVEPOINT first_purchase`.
5. Уменьшает количество «Уно» на 3.
6. Добавляет продажу «Уно» в `sales` с использованием `calculate_cost()`.
7. Отменяет вторую покупку командой `ROLLBACK TO SAVEPOINT first_purchase`.
8. Подтверждает оставшиеся изменения через `COMMIT`.

**Проверка:**

```sql
SELECT * FROM products ORDER BY id;
SELECT * FROM sales ORDER BY id;
SELECT * FROM stock_history ORDER BY id;
```

**Ожидаемый результат (после заданий 1–9):**

|---|---|

| История изменения остатка «Уно» от этой покупки | Отменена |
