# Практическое задание: работа с `TEMP VIEW`

Используя существующую базу данных транспортной системы, создайте несколько временных представлений.

Помните: `TEMP VIEW` существует только во время текущего подключения к базе данных.

## Задание 1. Активные карты

Создайте временное представление:

```text
temp_active_cards
```

Оно должно содержать только активные карты:

```text
deleted = 0
```

Выведите:

- `id`;
- `balance`;
- `created_at`.

Проверьте представление:

```sql
SELECT * FROM temp_active_cards;
```

---

## Задание 2. Карты с положительным балансом

Создайте временное представление:

```text
temp_positive_balance
```

В него должны попадать только:

- активные карты;
- карты с `balance > 0`.

Отсортируйте результат по балансу от большего к меньшему.

---

## Задание 3. Операции пополнения

Создайте `TEMP VIEW`:

```text
temp_deposits
```

которое содержит только операции:

```text
type = 'deposit'
```

Выведите:

- `card_id`;
- `amount`;
- `datetime`.

После создания определите общую сумму пополнений, используя `SUM()` над временным представлением.

---

## Задание 4. Статистика операций по картам

Создайте временное представление:

```text
temp_card_statistics
```

Для каждой карты оно должно содержать:

- `card_id`;
- количество операций — `transaction_count`;
- общую сумму операций — `total_amount`.

Используйте:

```text
GROUP BY
COUNT()
SUM()
```

После создания найдите в этом представлении карты, у которых количество операций больше `2`.

---

## Задание 5. Временный анализ станций

Создайте `TEMP VIEW`, которое показывает количество операций на каждой станции.

Используйте таблицы:

```text
transactions
      ↓
stations
```

В результате должны отображаться:

```text
station_name | line | transaction_count
```

Используйте `JOIN`, `COUNT()` и `GROUP BY`.

---

## Задание 6. Удаление временного представления

Удалите одно из созданных временных представлений:

```sql
DROP VIEW temp_deposits;
```

Попробуйте после этого выполнить:

```sql
SELECT * FROM temp_deposits;
```

Проанализируйте полученный результат.

---

## Задание 7. Проверка временности

1. Создайте любое `TEMP VIEW`.
2. Убедитесь, что оно работает с помощью `SELECT`.
3. Закройте текущее подключение к SQLite.
4. Повторно откройте базу данных.
5. Попробуйте выполнить запрос к созданному `TEMP VIEW`.

Объясните, почему временное представление больше не существует.
