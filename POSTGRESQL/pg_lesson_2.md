# Часть 1. Теоретический материал и демонстрация

## 2. Повторение PL/pgSQL

Перед изучением массивов напомните студентам структуру программного блока.

```sql
DO $$
DECLARE
    student_name TEXT := 'Александр';
    student_age INTEGER := 19;
BEGIN
    RAISE NOTICE 'Имя: %', student_name;
    RAISE NOTICE 'Возраст: %', student_age;
END;
$$;
```

**Объяснение преподавателя:** ранее мы создавали переменные, в которых хранилось одно значение. Например, `student_age` хранит одно число, а `student_name` — одну строку. Но если необходимо сохранить оценки десяти студентов, создавать десять отдельных переменных неудобно. Для этого существуют массивы.

## 3. Что такое массив в PostgreSQL?

**Массив (`ARRAY`)** — структура данных, позволяющая хранить несколько значений одного типа под одним именем.

Пример: `grades = ARRAY[5, 4, 3, 5, 2]`.

| Индекс | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| Значение | 5 | 4 | 3 | 5 | 2 |

Массивы, созданные обычным способом через `ARRAY[...]`, имеют индексы начиная с **1**. В PostgreSQL возможны и другие нижние границы индексов.

### 3.1. Создание массива

```sql
DO $$
DECLARE
    grades INTEGER[] := ARRAY[5, 4, 3, 5, 2];
BEGIN
    RAISE NOTICE 'Оценки: %', grades;
END;
$$;
```

- `INTEGER[]` — массив целых чисел.
- `ARRAY[...]` — создание массива.
- `grades` — имя переменной.

Результат: `NOTICE: Оценки: {5,4,3,5,2}`.

### 3.2. Получение элементов

```sql
DO $$
DECLARE
    grades INTEGER[] := ARRAY[5, 4, 3, 5, 2];
BEGIN
    RAISE NOTICE 'Первая оценка: %', grades[1];
    RAISE NOTICE 'Третья оценка: %', grades[3];
END;
$$;
```

Результат: первая оценка — `5`, третья — `3`.

### 3.3. Изменение элемента

```sql
DO $$
DECLARE
    grades INTEGER[] := ARRAY[5, 4, 3];
BEGIN
    grades[2] := 5;
    RAISE NOTICE 'Новый массив: %', grades;
END;
$$;
```

Результат: `{5,5,3}`.

### 3.4. Добавление элемента

```sql
DO $$
DECLARE
    grades INTEGER[] := ARRAY[5, 4, 3];
BEGIN
    grades := ARRAY_APPEND(grades, 2);
    RAISE NOTICE 'Массив: %', grades;
END;
$$;
```

Результат: `{5,4,3,2}`.

### 3.5. Полезные функции массивов

| Функция | Назначение |
|---|---|
| `ARRAY_LENGTH(arr, 1)` | Количество элементов по первому измерению (для пустого массива возвращает `NULL`) |
| `CARDINALITY(arr)` | Общее количество элементов (для пустого массива — `0`) |
| `ARRAY_APPEND(arr, value)` | Добавление элемента в конец |
| `ARRAY_PREPEND(value, arr)` | Добавление в начало |
| `ARRAY_REMOVE(arr, value)` | Удаление всех совпадающих элементов |
| `UNNEST(arr)` | Преобразование массива в набор строк |

**Мини-практика (3 минуты):** создайте массив из пяти чисел, измените третий элемент и добавьте шестой.

## 4. Перебор массива с помощью FOREACH

Цикл `FOREACH` позволяет последовательно обработать каждый элемент массива.

### 4.1. Пример перебора

```sql
DO $$
DECLARE
    numbers INTEGER[] := ARRAY[10, 20, 30, 40];
    num INTEGER;
BEGIN
    FOREACH num IN ARRAY numbers
    LOOP
        RAISE NOTICE 'Число: %', num;
    END LOOP;
END;
$$;
```

Результат:

```text
NOTICE: Число: 10
NOTICE: Число: 20
NOTICE: Число: 30
NOTICE: Число: 40
```

- `FOREACH` — цикл по элементам массива.
- `num` — переменная для очередного элемента.
- `IN ARRAY numbers` — массив для перебора.
- `LOOP ... END LOOP` — тело цикла.

### 4.2. Сумма элементов

```sql
DO $$
DECLARE
    numbers INTEGER[] := ARRAY[10, 20, 30, 40];
    num INTEGER;
    total INTEGER := 0;
BEGIN
    FOREACH num IN ARRAY numbers
    LOOP
        total := total + num;
    END LOOP;
    RAISE NOTICE 'Сумма: %', total;
END;
$$;
```

Результат: `100`.

**Вопрос студентам:** как изменить программу, чтобы она считала только сумму положительных чисел?

### 4.3. Подсчёт оценок

```sql
DO $$
DECLARE
    grades INTEGER[] := ARRAY[5, 4, 5, 3, 5, 2];
    grade INTEGER;
    count_fives INTEGER := 0;
BEGIN
    FOREACH grade IN ARRAY grades
    LOOP
        IF grade = 5 THEN
            count_fives := count_fives + 1;
        END IF;
    END LOOP;
    RAISE NOTICE 'Количество пятёрок: %', count_fives;
END;
$$;
```

Результат: `3`.

## 5. Заполнение массива из таблицы — ARRAY_AGG

До этого массивы создавались вручную. Теперь получим массив из данных таблицы.

### 5.1. Подготовка таблицы

> Выполняйте команды подготовки один раз в учебной базе. При повторном запуске `CREATE TABLE` для уже существующей таблицы возникнет ошибка.

```sql
CREATE TABLE students (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name VARCHAR(100),
    grade INTEGER
);

INSERT INTO students (name, grade)
VALUES
    ('Александр', 5),
    ('Мария', 4),
    ('Иван', 3),
    ('Анна', 5),
    ('Дмитрий', 4);
```

### 5.2. Использование ARRAY_AGG

`ARRAY_AGG()` — агрегатная функция, собирающая значения нескольких строк в один массив.

```sql
SELECT ARRAY_AGG(grade ORDER BY id)
FROM students;
```

Результат: `{5,4,3,5,4}`.

Объясните, что функция похожа на `SUM()` или `COUNT()`, но возвращает массив. `ORDER BY` внутри `ARRAY_AGG` обеспечивает нужный порядок элементов.

### 5.3. Сохранение результата в переменную

```sql
DO $$
DECLARE
    grades INTEGER[];
BEGIN
    SELECT ARRAY_AGG(grade ORDER BY id)
    INTO grades
    FROM students;

    RAISE NOTICE 'Оценки студентов: %', grades;
END;
$$;
```

`SELECT ... INTO` внутри PL/pgSQL записывает результат запроса в переменную.

### 5.4. Получение массива имён

```sql
DO $$
DECLARE
    student_names TEXT[];
BEGIN
    SELECT ARRAY_AGG(name::TEXT ORDER BY id)
    INTO student_names
    FROM students;

    RAISE NOTICE 'Студенты: %', student_names;
END;
$$;
```

`::TEXT` — приведение типа к `TEXT`.

**Мини-задание:** создайте массив оценок только тех студентов, у которых оценка не ниже 4. Выведите количество элементов. Помните: `ARRAY_AGG` возвращает `NULL`, если подходящих строк нет.

## 6. Заполнение таблицы из массива

### 6.1. Создание таблицы

```sql
CREATE TABLE exam_results (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    grade INTEGER
);
```

### 6.2. Вставка через FOREACH

```sql
DO $$
DECLARE
    grades INTEGER[] := ARRAY[5, 4, 3, 5, 2];
    grade INTEGER;
BEGIN
    FOREACH grade IN ARRAY grades
    LOOP
        INSERT INTO exam_results (grade)
        VALUES (grade);
    END LOOP;
END;
$$;

SELECT * FROM exam_results;
```

После выполнения добавятся пять записей.

### 6.3. Более простой способ — UNNEST

`UNNEST` превращает элементы массива в строки результата запроса.

```sql
SELECT UNNEST(ARRAY[10, 20, 30]);
```

| unnest |
|---|
| 10 |
| 20 |
| 30 |

Вставка массива в таблицу:

```sql
INSERT INTO exam_results (grade)
SELECT UNNEST(ARRAY[5, 4, 3, 5, 2]);
```

**Важно:** это альтернативный способ. Если выполнить оба примера вставки, таблица получит десять записей, а не пять. `FOREACH` полезен для изучения процедурной обработки, `UNNEST` обычно удобнее для массовой вставки.

# Часть 2. Работа с CSV-файлами

## 7. Что такое CSV?

**CSV (Comma-Separated Values)** — текстовый формат хранения табличных данных.

Пример `students.csv`:

```csv
name,grade
Александр,5
Мария,4
Иван,3
Анна,5
Дмитрий,4
```

Первая строка содержит заголовки, остальные — данные. CSV используют для обмена данными между электронными таблицами, базами данных и приложениями. В CSV могут использоваться кавычки для полей с запятыми и другими специальными символами.

## 8. Разница между COPY и \copy

| `COPY` | `\copy` |
|---|---|
| SQL-команда PostgreSQL | Метакоманда клиента `psql` |
| Файл читает или записывает сервер | Файл читает или записывает клиент |
| Путь относится к файловой системе сервера | Путь относится к компьютеру с `psql` |
| Для файлового доступа требуются соответствующие серверные права | Нужны права клиента на файл и права на таблицу |
| Выполняется в SQL-редакторе | Выполняется в `psql` |

Пример серверной команды `COPY` (путь и права должны подходить серверу):

```sql
COPY students_import(name, grade)
FROM '/server/path/students.csv'
WITH (FORMAT CSV, HEADER TRUE, ENCODING 'UTF8');
```

Для занятий на Windows удобнее использовать `\copy`, если файл расположен на компьютере студента.

## 9. Импорт CSV в PostgreSQL

### Шаг 1. Подготовить CSV-файл

Создайте каталог `C:\postgres_lab` и файл `students.csv` в кодировке UTF-8:

```csv
name,grade
Александр,5
Мария,4
Иван,3
Анна,5
Дмитрий,4
```

### Шаг 2. Создать таблицу

```sql
CREATE TABLE students_import (
    name TEXT,
    grade INTEGER
);
```

### Шаг 3. Выполнить импорт через psql

Подключитесь к учебной базе через `psql`, затем введите **одной строкой**:

```text
\copy students_import(name, grade) FROM 'C:/postgres_lab/students.csv' WITH (FORMAT CSV, HEADER TRUE, ENCODING 'UTF8');
```

- `FROM` — чтение из файла.
- `FORMAT CSV` — формат CSV.
- `HEADER TRUE` — пропустить первую строку с заголовками.
- `ENCODING 'UTF8'` — кодировка файла.

### Шаг 4. Проверить импорт

```sql
SELECT * FROM students_import;
```

Ожидается пять строк. Повторный импорт того же файла добавит строки ещё раз, если не очищать таблицу и не устанавливать ограничения уникальности.

**Вариант для pgAdmin:** контекстное меню таблицы → **Import/Export Data** → **Import**. Укажите файл, формат CSV, кодировку UTF-8 и наличие заголовка.

## 10. Экспорт данных из PostgreSQL в CSV

В `psql` выполните одной строкой:

```text
\copy students_import TO 'C:/postgres_lab/students_export.csv' WITH (FORMAT CSV, HEADER TRUE, ENCODING 'UTF8');
```

После выполнения в каталоге появится `students_export.csv`.

### Экспорт определённых данных

Экспортируем студентов с оценкой не ниже 4:

```text
\copy (SELECT name, grade FROM students_import WHERE grade >= 4) TO 'C:/postgres_lab/good_students.csv' WITH (FORMAT CSV, HEADER TRUE, ENCODING 'UTF8');
```

Это позволяет выгружать не всю таблицу, а результат отдельного SQL-запроса.
