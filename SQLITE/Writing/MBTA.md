## Практическое задание: проектирование базы данных транспортной системы

Необходимо спроектировать базу данных для простой системы оплаты проезда в общественном транспорте. Система должна хранить информацию о транспортных картах пассажиров, станциях и операциях, выполняемых с картами.

Создайте базу данных, состоящую из **трёх связанных таблиц**:

### 1. `cards` — транспортные карты

- Каждая карта должна иметь уникальный идентификатор `id`.
- `id` является первичным ключом.

### 2. `stations` — станции

Для каждой станции необходимо хранить:

- `id` — уникальный идентификатор;
- `name` — название станции;
- `line` — название или номер линии.

Название станции обязательно для заполнения и не должно повторяться.

### 3. `swipes` — операции с картами

Таблица должна хранить все действия пассажиров с транспортными картами.

Для каждой операции необходимо сохранить:

- `id` — идентификатор операции;
- `rider_id` — карту пассажира;
- `station_id` — станцию, на которой произошла операция;
- `amount` — сумму операции;
- `datetime` — дату и время;
- `type` — тип операции.

Требования:

- `rider_id` должен быть связан с таблицей `cards`;
- `station_id` должен быть связан с таблицей `stations`;
- значение `amount` не может быть равно `0`;
- если дата и время не указаны, они должны устанавливаться автоматически;
- поле `type` может принимать только три значения: `enter`, `exit` или `deposit`.

### Задание

Самостоятельно определите необходимые типы данных и ограничения:

- `PRIMARY KEY`
- `FOREIGN KEY`
- `NOT NULL`
- `UNIQUE`
- `CHECK`
- `DEFAULT`

После этого напишите SQL-команды `CREATE TABLE` для создания всей структуры базы данных.

## Практическое задание: импорт данных из CSV

Транспортная компания уже имеет данные о картах, станциях и поездках пассажиров. Данные были экспортированы из другой системы в формате **CSV**.

Необходимо импортировать подготовленные CSV-файлы в существующую базу данных.

### Файлы

Вам предоставлены три файла:

- `cards.csv` — транспортные карты;
- `stations.csv` — станции;
- `transactions.csv` — операции с картами.

### Задание

1. Изучите структуру каждого CSV-файла.
2. Сравните столбцы CSV с полями соответствующих таблиц.
3. Определите правильный **порядок импорта**, учитывая связи `FOREIGN KEY`.
4. Переключите SQLite в режим работы с CSV:

```sql
.mode csv
```

5. Импортируйте данные:

```sql
.import --skip 1 cards.csv cards
.import --skip 1 stations.csv stations
.import --skip 1 transactions.csv transactions
```

6. Проверьте результат:

```sql
SELECT * FROM cards;
SELECT * FROM stations;
SELECT * FROM transactions;
```

> **Важно:** сначала необходимо импортировать данные в родительские таблицы `cards` и `stations`, а затем в `transactions`, поскольку операции ссылаются на существующие карты и станции.
