# Практическая работа
## PostgreSQL — SQL-файлы, переменные и PL/pgSQL

**Цель работы:** закрепить навыки работы с PostgreSQL, создания таблиц, использования переменных, условий, циклов, массивов и получения данных из таблиц.

**Продолжительность:** 60–80 минут.

**Инструменты:** PostgreSQL, pgAdmin или psql, VS Code.

## Задание 1. Склад компьютерной техники

Создайте таблицу `equipment` со следующими столбцами:

- `id` — автоматически генерируемый идентификатор.
- `name` — название оборудования.
- `price` — стоимость.
- `quantity` — количество на складе.

Добавьте минимум 6 различных товаров.

### Необходимо выполнить

1. Вывести все товары.
2. Найти оборудование дороже 15 000 рублей.
3. Вывести товары, которых осталось меньше 5 штук.
4. Рассчитать общую стоимость всего оборудования на складе.

## Задание 2. Расчёт заработной платы

Используя PL/pgSQL, создайте программный блок `DO`.

Объявите переменные:

- `employee_name` — имя сотрудника.
- `salary` — первоначальная зарплата.
- `bonus_percent` — процент премии.
- `final_salary` — итоговая зарплата.

### Необходимо выполнить

1. Присвоить переменным произвольные значения.
2. Рассчитать премию сотрудника.
3. Вычислить итоговую зарплату с премией.
4. Вывести имя сотрудника, первоначальную и итоговую зарплату с помощью `RAISE NOTICE`.
5. Если итоговая зарплата превышает 100 000 рублей, вывести сообщение «Высокая заработная плата».

## Задание 3. Система оценки студентов

Создайте программный блок PL/pgSQL с переменными:

- `student_name` — имя студента.
- `score` — количество баллов.

В зависимости от количества баллов выведите результат:

| Баллы | Результат |
|---|---|
| 90–100 | Отлично |
| 75–89 | Хорошо |
| 60–74 | Удовлетворительно |
| 0–59 | Неудовлетворительно |

### Необходимо выполнить

1. Использовать `IF`, `ELSIF`, `ELSE`.
2. Проверить работу программы для разных значений.
3. Предусмотреть сообщение об ошибке, если баллы меньше 0 или больше 100.
4. Вывести имя студента, количество баллов и результат.

## Задание 4. Банковский счёт

Создайте таблицу `bank_accounts`:

- `id` — идентификатор счёта.
- `owner` — владелец.
- `balance` — баланс.

Добавьте минимум 3 счёта с разными балансами.

### Необходимо выполнить

Напишите блок PL/pgSQL, который:

1. Объявляет переменные `account_id` и `withdraw_amount`.
2. Получает текущий баланс указанного счёта из таблицы.
3. Проверяет, достаточно ли денег для снятия.
4. Если денег достаточно — уменьшает баланс.
5. Если денег недостаточно — выводит соответствующее сообщение.
6. Выводит итоговый баланс.
7. Предусматривает ситуацию, когда счёт с указанным идентификатором не существует.
