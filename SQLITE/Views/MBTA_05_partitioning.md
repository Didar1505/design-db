# Практическое задание: партиционирование данных

SQLite не поддерживает встроенное партиционирование таблиц, поэтому реализуйте его принцип с помощью отдельных таблиц и `VIEW`.

## Задание 1. Разделение операций по годам

Разделите данные таблицы `transactions` на две отдельные таблицы:

```text
transactions_2025
transactions_2026
```

Обе таблицы должны содержать поля:

- `id`;
- `card_id`;
- `station_id`;
- `amount`;
- `datetime`;
- `type`.

Добавьте несколько тестовых операций в каждую таблицу в соответствии с годом операции.

---

## Задание 2. Объединение партиций

Создайте представление:

```text
all_transactions
```

которое объединяет данные из:

```text
transactions_2025
transactions_2026
```

Используйте:

```sql
UNION ALL
```

После создания выполните:

```sql
SELECT * FROM all_transactions;
```

Затем:

1. Получите все операции за `2025` год.
2. Получите все операции за `2026` год.
3. Посчитайте общее количество операций из обеих партиций.
4. Добавьте новую операцию в `transactions_2026` и убедитесь, что она автоматически появляется в `all_transactions`.
